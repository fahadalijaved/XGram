🙏 Please • One problem per message, in English • Send logs only when an admin asks, and only privately: logs can contain private data • No ETA questions: fixes ship when they're ready 💡 Quick tips • Can't find a setting? Every page in Settings → XGram has a search button. • Ghost mode: chats you read stay unread on the server. Folder and app icon unread totals can still count them. • Channels are read normally in ghost mode, since they have no read receipts. • Icon packs are in Settings → Themes → Icon Set. Picking one restarts XGram once to apply it. • Message history saves messages you receive, for 30 days unless you change it in Settings → XGram → Message history. Your own deletions aren't kept, and media of deleted messages is only kept if you had downloaded it. • Transcribing voice messages needs Telegram Premium, and the Telegram AI tools have daily limits set by Telegram. • An update that won't install usually means an older build or one that isn't official.
